# Arenera Solichata

Prototipo visual inicial de la landing page comercial de Arenera Solichata.

## Abrir localmente

1. Clona o abre este repositorio.
2. Entra a la carpeta del proyecto.
3. Abre `index.html` directamente en tu navegador.

## Estructura

- `index.html`: estructura principal de la landing.
- `styles.css`: estilos visuales responsive.
- `script.js`: render de productos, galeria y acciones de WhatsApp.
- `assets/images`: imagenes del proyecto.

## Nota

Esta primera etapa es solo visual. Mas adelante se podran integrar Firebase Auth, Firestore, Storage y un panel administrativo.
